# 04_WECHAT_SPIKE：微信小游戏兼容性验证

只执行当前微信平台Spike任务，不同时开发玩法。

## 第一步：固定环境

- 读取 `ProjectVersion.txt`，记录Unity精确补丁。
- 记录Web Build Support模块。
- 重新核验当前官方微信Unity转换方案及其支持矩阵。
- 固定SDK版本或commit，不使用漂移分支。
- 保存来源、许可证、UPSTREAM、已知问题和移除本地补丁条件。

## 第二步：标准Unity Web

使用最小场景验证：

- 横屏与Safe Area。
- 单指输入和UI按钮。
- TextMeshPro中文。
- 一次音效播放及首次交互后的音频解锁。
- 协程。
- JSON配置加载。
- 暂停/恢复日志。

保存构建日志、耗时、体积和浏览器截图。

## 第三步：微信转换

- 不修改Gameplay代码绕过平台错误。
- 保存原始转换日志。
- 若第三方包在当前Unity编译失败，先记录原始错误，再写决策。
- 本地补丁必须最小、带版本条件、可移除。

## 第四步：开发者工具

验证启动、触控坐标、字体、音频、前后台、存档和异常日志。保存截图和版本。

## 第五步：真机

至少一台手机验证：

- 首次加载和二次加载。
- 横屏、安全区和触控。
- 连续快速划动。
- 音频。
- 前后台恢复。
- 3–5分钟内存和帧率。
- 重启后的存档。

## 结论

分别写 `Editor / Web / Transform / DevTools / Device` 五项结论。未执行的项必须是`BLOCKED`或`KNOWN ISSUE`，不能合并成“微信已通过”。
