# GAME_DESIGN_MVP：一笔镇妖玩法真相

## 1. 一句话定义

横屏2D手势动作游戏。玩家把手指划出的实时轨迹变成刀光或符线，在妖怪攻击命中前完成斩击、弱点打断、弹幕切断、一笔连斩和终极封印。

## 2. MVP体验目标

- 单关3～5分钟，首版包含3关。
- 单手、一根手指完成主要战斗；按钮只用于架势切换、终极和暂停。
- 玩家不自由移动，注意力集中在怪物前摇、弱点与屏幕空间。
- 普通划动立即攻击；复杂图形仅用于少量高价值技能。
- 核心爽点是一笔穿过多个目标、蓄力破甲、命中弱点打断、最后时刻切断弹幕、终极画符后的全屏封印。

## 3. 核心循环

```text
读取关卡配置
→ 倒计时
→ 敌人按波次与时间轴出现
→ 玩家划动攻击、打断、切弹、积累能量
→ 根据敌人切换刀/符架势
→ 终极能量满后点击按钮并完成指定笔势
→ 击败波次或Boss
→ 评分、奖励、解锁下一关
→ 重试或下一关
```

## 4. 输入与笔势

所有阈值均来自配置表，文档只定义语义。

| 笔势 | 语义 | MVP用途 |
|---|---|---|
| Any | 任意有效划动 | 当前普通攻击的统一笔势 |
| Horizontal / Vertical / Diagonal / Arc | 底层仍可识别的方向与曲率分类 | 当前普通战斗统一按Any处理，不产生独立效果或惩罚 |
| Circle | 接近闭合且面积足够 | 只用于终极封印；普通战斗中的圆形轨迹仍按Any处理 |
| Charged | 起笔停留达到阈值后再完成有效划动 | 普通战斗保留的蓄力破盾、破甲 |
| Triangle | 近似闭合、面积与角度足够且轨迹贴近三条边 | 普通战斗触发配置技能，使场上全部怪物减速 |

判定必须宽松、稳定、可回放。MVP不做机器学习手写识别。

当前内容有三种特殊笔势：普通战斗中的`Charged`与`Triangle`，以及终极绘制中的`Circle`。普通横线、竖线、斜线、弧线和圆形轨迹在非终极状态下统一进入`Any`规则；三角形命中后沿配置技能链给全部活动怪物施加减速。弱点是否命中以及是否处于打断窗口仍独立判定，三角形识别本身不直接包含减速逻辑。

## 5. 一笔规则

- 手指按下到抬起为一个 `strokeId`。
- 默认同一笔对同一目标只造成一次伤害；特殊技能可配置重复命中冷却。
- 根据目标在轨迹上的参数排序，形成真实的一笔命中顺序。
- 同一笔命中多个目标提升伤害、评分和能量，倍率在配置表维护。
- 划空不直接失败；危险目标、架势不匹配或漏掉攻击才造成惩罚。
- 轨迹视觉和命中必须使用同一组处理后的点，避免“看着命中但实际没中”。

## 6. 玩家

### 玄狸·墨砚

- 固定在战斗画面左侧，不自由移动。
- 生命、能量、架势、技能均配置化。
- 刀架势：轨迹较细，直接伤害、连斩与弱点倍率较高。
- 符架势：轨迹较宽，切弹、控场和幽魂伤害较强。
- 架势切换有冷却，并可配置即时效果。

### 终极技能：天地封妖令

点击终极按钮后进入 `UltimateDrawing`，时间减速，玩家必须完成配置指定的有效圆或符形事件。成功后执行效果链；取消或无效不能由计时器自动当作成功。

## 7. 敌人

首版使用通用状态机和可组合策略，不为每种怪物创建独立继承类。

| ID | 名称 | 核心教学点 |
|---|---|---|
| enemy_fire_fish | 符火鱼妖 | 基础目标，可切断其火符 |
| enemy_wheel_zombie | 轮车僵妖 | 地面推进，任意有效划动均可攻击 |
| enemy_stone_turtle | 石甲龟妖 | 正面护甲，保留蓄力破甲教学 |
| enemy_skeleton_ghost | 骷髅幽魂 | 漂浮曲线移动，符架势更有效 |
| enemy_talisman_bat | 飞行符蝠 | 快速俯冲，命中弱点并抓住窗口即可打断 |
| enemy_soul_puppet | 摄魂道傀 | 精英支援，为其他怪加盾 |
| boss_tomb_king | 镇墓玄甲王 | 三阶段Boss：符钉、封印弱点、冲撞处决；不要求指定方向 |

## 8. 关卡

| ID | 类型 | 内容 |
|---|---|---|
| lv_001_tutorial | 教学 | 普通斩、连斩、切弹、架势、终极，约6波 |
| lv_002_cave | 普通 | 混合敌人、危险目标、精英支援，约8波 |
| lv_003_boss | Boss | 镇墓玄甲王三阶段，约4分钟 |

敌人、波次、刷怪时刻、出生位置、Boss阶段、教程、星级阈值都由配置表维护。

## 9. 胜负与评分

- 胜利：关卡结束条件达成；Boss关为Boss死亡并完成结算事件。
- 失败：玩家HP归零；同一帧多个事件只能结算一次。
- 评分：伤害、命中数、弱点、连斩、弹反、无伤、剩余时间；普通笔迹形状本身不提供独立奖励。
- 星级阈值及奖励由表配置。

## 10. 体验底线

- 玩家无需查看Console即可理解命中、破甲、弱点、弹反和失败原因。
- UI不遮挡主要划动区；支持左右手按钮镜像。
- 前后台切换必须取消当前笔迹并安全暂停。
- 关卡关键门由玩家事件推进，计时器不能代替确认。
