# MVP_SCOPE：首版范围合同

## 必须完成

- Unity横屏2D、URP 2D Renderer、Input System。
- 微信小游戏四级验证：标准Web、微信转换、开发者工具、真机。
- 1名主角、2种架势、配置化基础技能、切换效果和终极。
- 5种普通怪、1种精英怪、1个三阶段Boss。
- 3关：教学、普通、Boss。
- 划动采样、简化、方向/弧/圆识别、命中排序、一笔去重。
- 敌方投射物切断和反弹。
- 数据驱动技能效果链、敌人策略、关卡刷怪和Boss阶段。
- 完整配置管线：Excel → 校验 → 稳定JSON → Runtime索引 → 测试。
- HUD、暂停、结算、重开、基础进度保存、中文字体。
- 对象池、性能预算、自动化测试和发布证据。

## 明确不做

- 玩家自由移动、复杂地图寻路、多人或联网对战。
- 抽卡、装备、角色养成、公会、日常任务和付费货币。
- 广告、内购、云存档、排行榜、分享裂变；平台接口可预留。
- 远程热更新配置和资源分包；包体超预算时另开决策。
- 多角色、多Boss、多场景主题。
- 机器学习手写识别和复杂书法评分。
- 正式剧情过场、全套骨骼动画和大量皮肤。

## MVP完成标准

1. 三关从开始、暂停、失败、重试、胜利到返回主菜单均可完成。
2. 所有玩法数值和内容列表由配置表驱动，Inspector不构成第二数值库。
3. EditMode、PlayMode、真实玩家路径分别有证据。
4. 至少一台目标低端机可稳定游玩，热路径无持续GC分配。
5. 微信四级验收均有独立结论；未执行层不允许写PASS。
6. 发布候选可追溯到Unity版本、SDK版本或commit、代码commit和配置hash。
