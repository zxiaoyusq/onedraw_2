# PSD资源接入摘要

当前PSD是可编辑的战斗概念界面，适合作为原型资源来源，但不是完整动画资源包。

## 已识别内容

- 2868×1320横版战斗构图。
- 红色幽冥洞穴当前背景，以及隐藏红色洞穴/森林方案。
- 黄衣灵猫主角和隐藏备选服装/动作草图。
- 符火鱼妖、轮车僵妖、石甲龟妖、骷髅幽魂、飞行符蝠。
- 生命条、终极、切换、设置按钮。
- 斩击轨迹、受击烟尘、伤害数字和鱼妖受击拆分状态。

## 工程判断

- 大多数主角与怪物是单张扁平Sprite，不能直接用于Spine/DragonBones骨骼动画。
- UI文字与框体多已合并，需要拆分动态血量和按钮状态。
- 背景有多层加工，但未按远景/中景/前景做干净视差拆分。
- 美术风格、线条与材质精细度存在差异，量产前需统一。
- 轮车僵妖图层名称带有生成图标记，正式商用前需确认来源与授权。

## 接入顺序

1. 原型阶段：直接导出静态透明PNG。
2. 建立Sprite导入规范、PPU、Pivot、图集和命名。
3. 先完成玩法闭环。
4. 按主角、普通敌人、Boss优先级拆件。
5. 补动画、VFX序列、UI多状态和背景视差。
6. 最后统一风格与压缩设置。
